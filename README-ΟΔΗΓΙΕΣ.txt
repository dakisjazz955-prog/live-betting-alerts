LIVE BETTING ALERTS — ΠΡΩΤΗ ΔΟΚΙΜΗ ΣΕ ΠΡΑΓΜΑΤΙΚΟ ΧΡΟΝΟ

Περιεχόμενα:
- app.py (αντικατάσταση του υπάρχοντος αρχείου)
- live_feed.py (ΝΕΟ αρχείο στη ρίζα του αποθετηρίου)
- requirements.txt (αντικατάσταση του υπάρχοντος αρχείου)

1. Άνοιξε https://dashboard.api-sports.io/ και δημιούργησε λογαριασμό.
2. Πάρε το API key από το dashboard. ΜΗΝ το στείλεις σε συνομιλία και ΜΗΝ το βάλεις σε δημόσιο GitHub.
3. Render -> Web Service -> Environment -> Add Environment Variable:
   API_SPORTS_KEY = [το ιδιωτικό σου κλειδί]
4. GitHub -> https://github.com/dakisjazz955-prog/live-betting-alerts/upload/main
   Ανέβασε app.py, live_feed.py και requirements.txt και κάνε Commit changes.
5. Μετά το επιτυχημένο Deploy, άνοιξε την πραγματική URL του Render.
   Πάτησε "Ζωντανό ποδόσφαιρο" ή "Ζωντανό μπάσκετ".
   Ενεργοποίησε "Παρακολούθηση για 15 λεπτά". Ανανέωση ανά 2 λεπτά,
   μόνο όσο η σελίδα παραμένει ανοιχτή.
6. Για live αποδόσεις ποδοσφαίρου, πάτησε το αντίστοιχο κουμπί.
   Προσοχή: οι αποδόσεις μπορεί να μην περιλαμβάνονται στο δωρεάν πλάνο.
   Αν δεν επιτρέπονται από τον πάροχο, θα εμφανιστεί μήνυμα αντί για ψευδή δεδομένα.

ΟΙ ΠΕΡΙΟΡΙΣΜΟΙ ΤΗΣ ΔΟΚΙΜΗΣ
- Δεν έχει γίνει πραγματική live δοκιμή εδώ γιατί δεν υπάρχει API key.
- Δεν στέλνονται αυτόματα live ειδοποιήσεις όσο είναι κλειστή η σελίδα.
- Η δωρεάν έκδοση του Render κοιμάται όταν δεν έχει επισκέψεις.
- Τα δεδομένα ανανεώνονται με βάση τα όρια του API-Sports (μπορεί να έχουν καθυστέρηση).
- Δεν υπάρχει αλγόριθμος value betting ούτε εγγύηση ότι οι αποδόσεις είναι διαθέσιμες στη Stoiximan.
- Η εφαρμογή δεν πραγματοποιεί αυτόματα στοιχήματα.

Για να γίνει μόνιμη ειδοποίηση στο παρασκήνιο, χρειάζονται σταθερός scheduler,
αποθήκευση συνδρομών push, VAPID key, και εξουσιοδοτημένα live feeds.
